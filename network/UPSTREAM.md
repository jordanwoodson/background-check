The complete source feature set is retained in this Android library. Local adaptations
include host identity, component/action names, kernel chain and boot-script isolation,
Background Check navigation/branding, Android SDK 36 and the host release toolchain.
The host supplies signing and versioning. No upstream signing/release files are imported.

Integration fixes add bounded/validated atomic backup restoration, IPv4/IPv6 failure
propagation and kernel health repair, truthful NPM capability labels/calibration,
filtered app shortcuts, and a sanitized public tile-preferences entry.

See [feature coverage and runtime evidence](../docs/network-controls-verification.md).
