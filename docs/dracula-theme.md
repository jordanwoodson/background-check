# Dracula identity

Background Check pairs the [Dracula palette](https://draculatheme.com/contribute) with rounded Material 3 surfaces and a Cana-inspired privacy shield containing a battery. The same mark appears in the launcher and both app workspaces.

Android sans-serif typography handles headings, prose, controls and dialog actions. Bundled [JetBrains Mono 2.304](https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304) identifies measurements and package IDs. Its Regular, Medium, SemiBold and Bold weights work offline; the font license and provenance ship in the APK assets. Purple tonal selection, larger corner radii and explicit status labels support the expressive direction without changing enforcement or access requirements.

The theme covers Overview, Apps, Monitor, Access and the Views-based Network workspace, including app/process/battery details, sorting menus, policy confirmations and messages. Navigation adapts to text size and window width. See [current screenshots and verification](ux-2026-verification.md).

| RAM trend | `#FF79C6` |
| Errors | `#FF5555` |
| Secondary text | `#B4BEDB` |

Dracula's comment color (`#6272A4`) is used for outlines rather than small body text. The lighter secondary text has 7.68:1 contrast on the background and 8.52:1 on panels. Status labels remain explicit rather than relying on color. Battery state sits on its own line so large text does not crowd the percentage.
